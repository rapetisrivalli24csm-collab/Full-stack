# Student Profile using JavaScript

## Task
Create a Student class using JavaScript and dynamically display a student profile using DOM manipulation.

## Files
- `index.html` - webpage structure and input form
- `style.css` - basic styling
- `script.js` - Student class, object creation, DOM manipulation and event handling

## Sample Input
Name: Ravi Kumar
Roll No: A23126552001
Department: CSE (AI & ML)
CGPA: 8.42

## Expected Output
Student Profile

Name       : Ravi Kumar
Roll No    : A23126552001
Department : CSE (AI & ML)
CGPA       : 8.42
